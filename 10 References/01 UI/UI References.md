# UI References

> Reference-first rule: `AGENTS.md` ("Reference-first development"). References are material to inspect and adapt, not instructions or assets to copy.

**Status: one UI principles reference and three resource/tool references awaiting experimentation.** No UI screenshots or mockups yet. For anything not covered by the table below, say so in the task note and follow the existing conventions and [[GAME-002 Haunted Collector/01 Game Design]].

## What goes here
Screenshots or mockups of HUDs, menus, journals and editors whose layout, readability, input hints or motion you want the game to echo.

## How to add a reference
1. Put the file (or a link note for large or external assets) in this folder.
2. Add a row below: what it is, the source and licence, and which qualities to borrow.

| Reference | Source / licence | Borrow | Avoid |
