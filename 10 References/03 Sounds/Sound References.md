# Sound References

> Reference-first rule: `AGENTS.md` ("Reference-first development"). References are material to inspect and adapt, not instructions or assets to copy.

**Status: empty.** No sound references have been added yet. Until there are, say so in the task note and follow the existing conventions and [[GAME-002 Haunted Collector/01 Game Design]].

## What goes here
Creator Store asset IDs or descriptions of ambience, stingers and UI sounds, with the mood each should set. Sourcing goes through the `roblox-sfx` skill.

## How to add a reference
1. Put the file (or a link note for large or external assets) in this folder.
2. Add a row below: what it is, the source and licence, and which qualities to borrow.
