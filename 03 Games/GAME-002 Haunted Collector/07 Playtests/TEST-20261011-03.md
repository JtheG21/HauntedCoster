# Playtest: fresh-profile first session (brief §20) through the real client

## Setup
- **Place:** `HauntedCollector.rbxl`, unpublished, memory-only saving. The banner "Test mode: DataStores unavailable, progress is NOT saved" showed the whole time.
- **Build:** commit `4696529` on `task/TASK-0011-…`, live-synced with `rojo serve haunted.project.json`. One player, fresh profile, Studio Play.
- **Driver:** Claude, through the Studio MCP, with no server shortcuts: no coin grants, no back-dated timers, no teleports.
  - **Input:**
    - The MCP keyboard and mouse tools for every UI button, key (M, J, Space) and editor tap.
    - MCP pathfinding navigation, or `Humanoid:MoveTo`, for walking.
    - `ProximityPrompt:InputHoldBegin/End` for world prompts. MCP key presses didn't reliably reach ProximityPromptService, so prompts were held through their own API, the same one custom prompt UIs use, which goes through the engine to the server.
  - **Capture:** CATCH was pressed with real Space presses about 0.5 s apart. The meter timing was not scripted.
- **What this is not:** a human feel and pacing judgement. Timings include tool latency (each MCP call takes about 2–10 s) and time spent investigating problems. They are an upper bound, not a measure of pacing.

| F1 | minor | Walking to the station (as step 1 tells you to) touch-sat the player in the cart's open **GuestSeat**. Pathfinding back out kept re-seating them. | GuestSeat touch-sitting off; a "Hop in" prompt (R / Y) seats a guest. `TrainService.luau` |

| F3 | **major** | **Track editor taps landed about 8.6 studs above the cursor** (mouse and touch). `input.Position` excludes the 58 px top-bar inset, but it was passed to `ViewportPointToRay`. Clicking a point added a new point instead of selecting it. The gamepad cursor (already in viewport space) was unaffected. | Add `GuiService:GetGuiInset()` before `groundHit`. `TrackEditor.luau` |
| F4 | minor | ProximityPrompt billboards (the station's Ride) stayed active over the top-down editor and swallowed taps. | `ProximityPromptService.Enabled = false` while the editor is open. `TrackEditor.luau` |
