## Setup
- **Place:** `Place1`, the HauntedCollector place (local, unsaved, `StreamingEnabled = true`). Tester: Claude via Studio MCP. jg was away.
- **Sync method (not Rojo):**
  - `rojo serve haunted.project.json` ran from the TASK-0041 worktree (port 34872). Studio's Rojo plugin wasn't connected, and its toolbar can't be reached by accessibility, so I couldn't click Connect.
  - Instead, each changed file was written into Studio as script `Source` through Studio MCP `execute_luau`. Each Studio copy was checked against its disk file with a length plus 31-polynomial hash, and every file matched.

### Performance (static count)
16 trees, 415 BaseParts, 431 instances in total. Faced trees use 30–38 parts, plain trees 13–20. No lights, no textures, no per-tree scripts. The client runs one `BindToRenderStep`. On the server, a `task.delay` per tree runs only while that tree has observers or a resume pending. No frame-time profiling was done.
