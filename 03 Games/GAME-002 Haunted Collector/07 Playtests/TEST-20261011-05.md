# Playtest: dark section and flashlight (TASK-0012 AC2)

## Setup
- `HauntedCollector.rbxl`, memory-only, live-synced from `rojo serve haunted.project.json` on the TASK-0011 branch. One player, Studio Play, `Lighting.ClockTime` 0.
- Walked (pathfinding navigation, no teleport) into **Mausoleum Hollow** (`dark = true`) at about (70, 3, -270) and (40, 3, -300).
- The Sealed Crypt, the other dark zone, wasn't captured: it was gated in this fresh profile.

## Procedure & results
| Step | Expected | Actual | Pass? |
|---|---|---|---|
| Flashlight on by default, no battery | Beam lights the area ahead | `assets/TEST-20261011-05-hollow-light-on.jpg`: mausoleum, graves, crosses and the ground in front are clearly lit. No battery UI or drain exists in code (`LocalWorld.luau` toggle only) | ✅ |
| PC: F toggles off | Area goes dark | `assets/TEST-20261011-05-hollow-light-off.jpg`: only silhouettes against the night ambient. The fix is verified by the label text read in the client (row "Label fix"), not by a new capture.* | ✅ light / ❌ label → fixed |
| Mobile path: tap the HUD Light button | Toggles | Clicking the button turned the SpotLight back on, label "Light: ON". The same TextButton receives touch taps. A real touch device or emulator was **not** used | ✅ (mouse) |
| Gamepad: DPadUp (revision 1 binding) | Toggles | MCP virtual gamepad input refused it: "key is permanently bound to a CoreGUI core action" | ❌ → moved |
| Gamepad: DPadDown (revision 2 binding) | Toggles | Virtual gamepad DPadDown → SpotLight off, label "Light: OFF". DPadDown, ButtonL1 and ButtonL3 were all accepted; the game uses no other DPadDown binding. A physical controller wasn't used | ✅ (virtual gamepad) |
| Label fix | Label follows F/DPadDown toggles | After the fix: F → SpotLight off, label "Light: OFF" | ✅ |
| Paths and obstacles readable in the dark | Readable with the light | `assets/TEST-20261011-05-hollow-path-light-on.jpg`: nearby headstones and crosses read clearly; ground-level path edges outside the beam are hard to see. **A human readability judgement is still needed.** | ⚠️ judgement for jg |
