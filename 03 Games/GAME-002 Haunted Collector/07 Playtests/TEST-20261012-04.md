# Playtest: cemetery vignette and atmosphere (TASK-0028)

## Setup
- `HauntedCollector.rbxl`, memory-only, live-synced from `rojo serve haunted.project.json`.
- Lighting was tuned live on the client in Play over several rounds, then written into `Atmosphere.Config` and `Props.lantern`. The saved captures were taken in a fresh Play session with the committed values: the server applied the earlier round, and the last adjustment (OutdoorAmbient 150/160/185, Brightness 1.4, lantern range 30 and brightness 2.6) was applied live on the client before the first saved capture. These are the values now in code.
- Flashlight off: every light on the character was disabled before capturing. The camera sat 100–200 studs from the character anyway.
- Everything was run by Claude through Studio MCP. Nobody played hands-on.
