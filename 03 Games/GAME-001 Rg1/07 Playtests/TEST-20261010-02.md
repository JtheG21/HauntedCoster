## What the code implies (inference, not evidence)
Luau runs Touched handlers one at a time on one thread. `onTouched` reads `Active`, validates, and calls `setActive(coin, false)` **before any yield**, so a second handler for the same coin should see `Active=false` and reject the touch. This has to be confirmed by the procedure below.
