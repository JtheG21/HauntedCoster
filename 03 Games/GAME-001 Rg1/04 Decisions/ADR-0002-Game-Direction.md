# ADR-0002: Direction is an anime-inspired rival co-op physics obby

## Context
M1 compared 4 concepts ([[RSH-20261010-Candidate-Comparison]]). The co-op physics obby (A) ranked first.

## Decision (approved by the user in chat, 2026-10-10)
Build **one** game: an anime-inspired co-op physics obby where players are **rivals by nature** but must **use each other's powers** at certain points to progress. The match ends in a **last-one-standing fight** using the abilities they've learned. Core fantasy: settle "which anime is best", answered **in more ways than combat**. Inspirations named by the user: Naruto, Dragon Ball Z, One Piece, Bleach (how we handle the IP: [[ADR-0003-Original-Factions-IP-Policy]], proposed).

## Consequences
- This adds PvP and four ability kits on top of candidate A. Scope and technical risk are **higher** than in the comparison (re-assessed in [[GAME-001 Rg1/01 Game Design|01 Game Design]]).
- Concepts B, C and D are archived for now.
