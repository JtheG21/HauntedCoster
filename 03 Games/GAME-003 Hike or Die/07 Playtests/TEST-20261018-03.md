# Playtest Hike or Die Gate 1 local Studio smoke

## Setup
Hike or Die local place, placeId `125955495785089`, one player, Studio MCP Play session. Rojo served `hike-or-die.project.json` from the task worktree on port 34872. The inherited Haunted Collector server/client scripts and default Baseplate/SpawnLocation were removed from this Hike or Die place after verifying their class and source role; the GAME-003 mapped folders were retained. This is an internal smoke test, not a fresh-player study.

## Console output / errors
HOD boot message was present. No HOD Lua error appeared in the Studio console. Studio also emitted asset-type mismatch messages for `rbxassetid://203785492` and repeated UIBlox `FoundationProvider not found` warnings; these were Studio/core output and were not traced to GAME-003 code.

## Not covered

This local smoke test does not establish fairness, fun, product-market fit, persistence, co-op, or release readiness.
