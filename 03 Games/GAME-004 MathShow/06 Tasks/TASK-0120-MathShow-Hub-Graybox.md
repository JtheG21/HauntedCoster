### Measurements (Studio, WalkSpeed 16, JumpHeight 7.2, R15)
Path length from PathfindingService (agent radius 2, height 5, can jump), time = length / 16. Centre is (0, 3, 0), spawn is (0, 3.6, 47).

| Pad | Centre to pad | Spawn to pad |
|---|---|---|
| Blitz (E) | 150 studs, 9.4 s | 165, 10.3 s |
| VS (E) | 159, 9.9 s | 166, 10.4 s |
| Group (E) | 158, 9.9 s | 173, 10.8 s |
| Practice (W) | 164, 10.2 s | 169, 10.5 s |
| Skill (W) | 163, 10.2 s | 168, 10.5 s |
| Daily (N, +32 terrace) | 180, 11.2 s | 227, 14.2 s |

All six are inside 8-12 s from the plaza centre. Spawn to Daily is 14.2 s, the only outlier and not a target; a shorter ramp run or a closer terrace would fix it if it matters.

Reachability: pathfinding found a route from spawn to all 34 GlyphSpawn markers (21 common, 13 rare), 0 unreachable. `character_navigation` walked the character to Terrace3, Terrace2 and Terrace1 and ended within 0.9, 3.1 and 0.8 studs of the targets (earlier build: Pad_Daily, Roof2, Tier5, Lake2).

Performance (Play, 1047x669 viewport, new geometry): 60.2 fps average (vsync-capped), worst frame 33.9 ms, 0 lights, 426 hub BaseParts.
