### Hook security review (focus items)
- **Live servers:** `RunService:IsStudio()` is false, so the hook returns before it touches `StudioTestService`. No-op confirmed by reading the code.
- **Normal Studio play / Run:** `GetTestArgs()` is wrapped in `pcall`. A non-table result, or a table without a string `scenario`, returns early. No-op confirmed.
- **Module lookup:** `FindFirstChild(args.scenario)` on the fixed folder `TestService.Tests.multiclient`, plus an `IsA("ModuleScript")` check. `FindFirstChild` treats the name literally (no dots or path segments), so there is no traversal and no arbitrary require. Only a caller with plugin security in Studio can set the args. **Acceptable to ship.** The scenario modules ship in the built place, because `TestService/Tests` is in `default.project.json`, but they stay inert.
- **TestRunner interaction:** the runner only picks up `*.spec` children of `Tests`, so `multiclient/CollectibleRace` is never run as a spec.
- **EndTest coverage:** a missing scenario, a missing `Tests` folder (10 s timeout), and a scenario that throws all reach `EndTest`. Gaps are listed in finding 3.

### Scenario review
- Every wait loop is bounded: `waitFor` checks a deadline, so the worst case is about 30 + 20·n + 20·n + rounds·12.5 + 2·10 s. `os.clock` advances across yields in Roblox.
- **Same-frame PivotTo:** true on the server, because there is no yield between the PivotTo calls. However, character touches come from client-owned physics and are replicated. The same server frame for the teleport does not imply that both players' touches reached `onTouched` in the same batch (finding 1).
- The type casts are sound for the spawned coins and characters. A player who leaves mid-test makes `(player.Character :: Model)` nil, and the error lands in the hook's `pcall`, so `EndTest` is still called.
- The game's debounce in `CollectibleService.onTouched` (`setActive(coin,false)` before any yield) is correct by inspection, independent of the harness.
