## Findings
| # | Severity | Finding | Evidence | Suggested fix |
|---|---|---|---|---|
| 1 | minor | The type-check gate is machine-specific and fails open. It reads Roblox definitions from a macOS VS Code globalStorage path. When the file is missing it prints SKIP and exits 0, so on CI or another machine `check.sh` reports `PASS: scripts/typecheck.sh` even though no type check ran. It is also tooling outside the spec's file list. | `scripts/typecheck.sh:5-6`, `scripts/check.sh:11` | Allow a `LUAU_DEFS` env override. Make the summary say SKIP instead of PASS, for example by having `run` treat exit code 2 as skipped. Or move the gate to its own approved task. |
| 2 | minor | Pickup has no movement or rate sanity check. A client owns its character's physics, so an exploiter can teleport next to every coin, or replicate touches with `firetouchinterest`, and collect all `Count` coins in a few frames. With `MaxPickupDistance = 12`, a spoofed touch also works from about 10 studs away. A real touch from the HRP to a 2.5-stud coin needs about 5-6 studs. | `CollectibleConfig.luau:9`, `CollectibleService.luau:55` | This is acceptable for a prototype with no persistence. Before coins gain any value, lower `MaxPickupDistance` to about 6-7 (verify tools and R15 avatars in a playtest) and add a per-player pickup rate cap, or a speed or teleport check, in `CollectibleRules`. |
| 3 | minor | Character detection uses the nearest `Model` ancestor. That works for accessories (Accessory is not a Model) and for equipped Tools (Tool is not a Model). It breaks if a character ever contains a nested `Model`, such as a custom rig part or a model-based gear item, because the hit then resolves to the inner model and the touch is silently ignored. | `CollectibleService.luau:46-47` | Walk up the ancestors: find the first ancestor `m` where `Players:GetPlayerFromCharacter(m)` is non-nil. Or check `hit:IsDescendantOf(player.Character)`. |
| 4 | minor | The service wiring is never tested automatically. The debounce, the respawn, the leaderstats setup and the ancestry detection all live in the service, and none of them have tests. The specs test only the pure rules. The executor's playtest covered single-player cases, but the 2-player simultaneous touch (spec step 6) was not verified. | spec "Not yet verified", `tests/luau/CollectibleRules.spec.luau` | Run playtest step 6 by hand before merging. Optionally, extract a small `tryCollect(coinState)` state transition into the rules module and unit-test that a second call returns false. |
| 5 | nit | A hidden coin still has `CanQuery = true`, so raycasts and spatial queries hit invisible coins. | `CollectibleService.luau:39-43` | Set `coin.CanQuery = active` in `setActive`. |
| 6 | nit | The spec lists a `SpawnArea` config field. The implementation uses `SpawnCenter` and `SpawnRadius` instead. That is equivalent and reasonable, but it differs from the spec. | `CollectibleConfig.luau:10-11`, spec "Files expected to change" | Note the rename in the spec's Outcome, or rename the field. |
| 7 | nit | Out-of-scope edits to `tests/luau/Smoke.spec.luau` (typed `t`) and `TestRunner.luau` (`pcall(fn :: any)`). Both are harmless and only exist to satisfy the new strict type gate. | diff of those files | Keep them, but list them under the same tooling item as finding 1. |

Checked and found no problem: leaderstats timing relative to PlayerAdded (the `GetPlayers` loop covers it). A player leaving between touch and award (`getCoins` returns nil, or the Value write lands on an orphaned instance, which is harmless). Respawn after the coin is destroyed (the `coin.Parent` guard holds because `Destroy` nils the parent). Dead or respawning characters (no HRP gives distance nil, which rejects the touch). `CanTouch` toggling (it stops event spam while the coin is inactive, and re-enabling it while a player is standing on the coin fires a new touch, which is the correct behavior). Performance: 10 connections that are never disconnected, but the coins live for the whole session, and nothing runs every frame. No remotes were added.
